# Youarel

A launcher that opens your web shortcuts from any browser and syncs them end-to-end encrypted, with or without a server.

## Installation

```sh
git clone https://github.com/P4suta/youarel.git
cd youarel
mise install
```

## Usage

```sh
just check
just proofs
```
